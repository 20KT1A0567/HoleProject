Anusha Bazaar Admin Panel - UI, Layouts, and Colors Guide
==========================================================

1. OVERVIEW OF UI AND STYLING
----------------------------------------------------------
The Anusha Bazaar Admin Panel uses a modern, premium "Glassmorphism" aesthetic with "Liquid" visual effects. It is built using React (Vite), Tailwind CSS v4, and Material-UI (MUI), relying heavily on custom CSS variables to handle light and dark themes smoothly.

Key Design Elements:
- Typography: 'Inter', system-ui, sans-serif.
- Glassmorphism: Cards and panels use semi-transparent backgrounds with backdrop blur filters (backdrop-filter: blur(24px)).
- Liquid Buttons: Buttons use an intricate combination of linear and radial gradients with inner/outer box-shadows to look like shiny, tactile objects.
- Scrollbars: Custom styled with transparent tracks and gradient thumbs.

2. COLORS AND THEMES
----------------------------------------------------------
The application utilizes a CSS variable root system for dynamic theme switching.

Light Theme:
- Background: #f8fafc to #eef2ff
- Sidebar: Linear gradient from dark slate (#111827) to deep indigo (#312e81)
- Cards: Translucent white (rgba(255, 255, 255, 0.84))
- Text: Dark slate (#0f172a)
- Accent (Primary): Indigo (#4f46e5)

Dark Theme:
- Background: #0b1120 to #111827
- Sidebar: Linear gradient from slate (#111827) to deeper slate (#1e293b)
- Cards: Translucent dark slate (rgba(15, 23, 42, 0.82))
- Text: Off-white (#f8fafc)
- Accent (Primary): Light indigo (#6366f1)

3. LAYOUT STRUCTURE
----------------------------------------------------------
The primary layout is the `DashboardLayout`, structured using a flexbox shell that encompasses the entire viewport height.

- Shell: Fixed to 100vh, hidden overflow, holding the background.
- SideNav: Fixed on the left side.
- Main Area: A flex column containing the AppBar at the top and a scrollable `<main>` area below it.
- Content Container: Inside `<main>`, constrained to a maximum width of 1600px and centered.

==========================================================
STEP-BY-STEP GUIDE: APPLYING THIS STYLING TO A NEW PROJECT
==========================================================

If you want to add another project with the exact same styling, follow these steps:

STEP 1: Initialize Your Project
-------------------------------
Create a new Vite React project and install dependencies.
```bash
npm create vite@latest new-admin-panel -- --template react-ts
cd new-admin-panel
npm install
npm install -D tailwindcss @tailwindcss/postcss postcss
```

STEP 2: Setup Tailwind CSS
--------------------------
Configure PostCSS and Tailwind. Ensure your tailwind.config.ts looks like this:
```typescript
import type { Config } from 'tailwindcss';
export default {
  content: ["./index.html", "./src/**/*.{js,jsx,ts,tsx}"],
  theme: { extend: {} },
  plugins: [],
} satisfies Config;
```

STEP 3: Import Fonts and Global Styles
--------------------------------------
Replace the contents of your `src/index.css` with the Anusha Bazaar styling variables. Make sure to include the Google Font import and the custom classes:

```css
@import 'tailwindcss';
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&display=swap');

/* Global Reset and Font */
body {
  margin: 0;
  font-family: 'Inter', system-ui, sans-serif;
  -webkit-font-smoothing: antialiased;
  transition: background-color 0.3s ease, color 0.3s ease;
}

/* Light Theme Variables */
:root, .light-theme {
  --color-bg: #f8fafc;
  --color-shell: #f8fafc;
  --color-card: rgba(255, 255, 255, 0.84);
  --color-text: #0f172a;
  --color-accent: #4f46e5;
  --color-border: rgba(148, 163, 184, 0.22);
  --glass-blur: blur(24px);
  --shadow-card: 0 20px 48px rgba(15, 23, 42, 0.08);
  --content-panel-bg: linear-gradient(180deg, rgba(255, 255, 255, 0.42) 0%, rgba(255, 255, 255, 0.72) 100%);
}

/* Dark Theme Variables */
.dark-theme {
  --color-bg: #0b1120;
  --color-shell: #0b1120;
  --color-card: rgba(15, 23, 42, 0.82);
  --color-text: #f8fafc;
  --color-accent: #6366f1;
  --color-border: rgba(71, 85, 105, 0.72);
  --glass-blur: blur(22px);
  --shadow-card: 0 20px 48px rgba(2, 8, 23, 0.45);
  --content-panel-bg: linear-gradient(180deg, rgba(15, 23, 42, 0.38) 0%, rgba(11, 17, 32, 0.18) 100%);
}

/* Reusable UI Classes */
.admin-card {
  background: var(--color-card);
  border: 1px solid var(--color-border);
  border-radius: 22px;
  box-shadow: var(--shadow-card);
  backdrop-filter: var(--glass-blur);
  -webkit-backdrop-filter: var(--glass-blur);
}

.liquid-button {
  padding: 0.85rem 1.4rem;
  border-radius: 999px;
  background: var(--color-accent);
  color: #fff;
  font-weight: 700;
  cursor: pointer;
  box-shadow: 0 18px 34px rgba(79, 70, 229, 0.22);
}
```

STEP 4: Create the Layout Structure
-----------------------------------
Create `src/layouts/DashboardLayout.tsx`. Use inline styles that reference your CSS variables to recreate the shell:

```tsx
import React from 'react';

const DashboardLayout: React.FC<{ children: React.ReactNode }> = ({ children }) => {
  return (
    <div className="admin-panel-shell" style={{ display: 'flex', height: '100vh', overflow: 'hidden', background: 'var(--color-shell)' }}>
      {/* Sidebar Placeholder */}
      <aside style={{ width: '260px', background: 'var(--color-sidebar)', color: '#fff' }}>
        <div style={{ padding: '20px', fontWeight: 'bold' }}>SideNav</div>
      </aside>

      {/* Main Content Area */}
      <div style={{ display: 'flex', flexDirection: 'column', flex: 1, background: 'var(--content-panel-bg)' }}>
        {/* Header Placeholder */}
        <header style={{ height: '70px', borderBottom: '1px solid var(--color-border)', padding: '20px' }}>
          AppBar
        </header>
        
        {/* Scrollable Page Content */}
        <main style={{ flex: 1, overflowY: 'auto' }}>
          <div style={{ padding: '24px', maxWidth: 1600, margin: '0 auto', color: 'var(--color-text)' }}>
            {children}
          </div>
        </main>
      </div>
    </div>
  );
};

export default DashboardLayout;
```

STEP 5: Build Reusable Components
---------------------------------
Whenever you build components (tables, forms, statistics boxes), wrap them in a `div` containing the `admin-card` class so they inherit the glassmorphism UI.

Example Card:
```tsx
<div className="admin-card p-6">
  <h2 className="text-xl font-bold mb-4">Total Users</h2>
  <p className="text-gray-500">View your platform's user statistics here.</p>
  <button className="liquid-button mt-4">View Details</button>
</div>
```

STEP 6: Apply Theme Switching
-----------------------------
To switch between Light and Dark mode, toggle the `dark-theme` and `light-theme` classes on the `document.body` element in your React app.

```typescript
const toggleTheme = (isDark: boolean) => {
  if (isDark) {
    document.body.classList.add('dark-theme');
    document.body.classList.remove('light-theme');
  } else {
    document.body.classList.add('light-theme');
    document.body.classList.remove('dark-theme');
  }
};
```

================================================================================
          ANUSHA TECHNOLOGIES - ADMIN PANEL API DOCUMENTATION
              Complete API Reference for Frontend Team
                      Base URL: http://localhost:8080
================================================================================

IMPORTANT NOTES:
- All admin APIs require JWT Bearer Token in Authorization header
  Header: Authorization: Bearer <accessToken>
- Admin roles: ROLE_ADMIN or ROLE_SUPER_ADMIN
- Super Admin has access to everything
- Regular Admin access is permission-based (per module)
- Token expiry is checked on every request
- All dates/times are in ISO 8601 format (e.g., "2026-04-24T10:30:00")

  1. ADMIN AUTHENTICATION
     Base URL: /api/auth/adminpanel
     Auth Required: NO (these are login endpoints)
================================================================================

------------------------------------------------------------------------
1.1  LOGIN WITH EMAIL & PASSWORD
------------------------------------------------------------------------
Method : POST
URL    : /api/auth/adminpanel/login

Request Body:
{
  "email": "admin@anushatechnologies.com",
  "password": "Admin@123"
}

Response (Success - No 2FA Code):
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
  "refreshToken": "dGhpcyBpcyBhIHJlZnJlc2g...",
  "expiresIn": 86400,
  "id": 1,
  "email": "admin@anushatechnologies.com",
  "role": "ROLE_ADMIN",
  "name": "Admin User",
  "mustChangePassword": false,
  "adminCodeRequired": false,
  "adminCodeChallengeToken": null,
  "adminAccessExpiresAt": "2026-04-30T10:00:00",
  "adminAccessRemainingSeconds": 518400,
  "adminAccessExpired": false,
  "permissions": ["orders", "customers", "products", "delivery"]
}

Response (Success - 2FA Code Required):
{
  "id": 1,
  "email": "admin@anushatechnologies.com",
  "role": "ROLE_ADMIN",
  "name": "Admin User",
  "mustChangePassword": false,
  "adminCodeRequired": true,
  "adminCodeChallengeToken": "challenge_token_abc123xyz",
  "permissions": ["orders", "customers"]
}

NOTE: If adminCodeRequired = true, you MUST call endpoint 1.3 to verify the
      6-digit access code before getting the actual JWT tokens.

Response (Error):
{
  "message": "Bad credentials"
}

------------------------------------------------------------------------

URL    : /api/super-admin/admin-users/{id}/access-code

URL Example: /api/super-admin/admin-users/5/access-code

Request Body:
{
  "code": "123456"
}

Response: Updated AdminUserResponse object

------------------------------------------------------------------------
2.6  SET ADMIN PERMISSIONS (Which modules can be accessed)
------------------------------------------------------------------------
Method : PUT
URL    : /api/super-admin/admin-users/{id}/permissions

URL Example: /api/super-admin/admin-users/5/permissions

Request Body:
{
  "permissions": ["orders", "customers", "delivery", "products", "coupons", "banners"]
}

Available permission keys (send as array of strings):
  "orders"          - Order management
  "customers"       - Customer management
  "delivery"        - Delivery person management
  "products"        - Product management
  "stores"          - Store management
  "categories"      - Category management
  "coupons"         - Coupon management
  "banners"         - Banner management
  "analytics"       - Dashboard and analytics
  "notifications"   - Push notification management
  "audit"           - Audit logs

Response: Updated AdminUserResponse object

------------------------------------------------------------------------
2.7  SET ADMIN ACCESS DURATION (How long admin can access panel)
------------------------------------------------------------------------
Method : PUT
URL    : /api/super-admin/admin-users/{id}/access-time

URL Example: /api/super-admin/admin-users/5/access-time

Request Body:
{
  "days": 7,
  "hours": 0,
  "minutes": 0,
  "seconds": 0
}

Response: Updated AdminUserResponse object

}

Bulk Action Values:
  ACTIVATE            - Enable all selected products
  DEACTIVATE          - Disable all selected products
  DELETE              - Delete all selected products
  MOVE_CATEGORY       - Move to different category (requires categoryId)
  MOVE_SUBCATEGORY    - Move to subcategory (requires subCategoryId)
  MOVE_STORE          - Move to different store (requires storeId)
  SET_DISPLAY_ORDER   - Set exact display order (requires displayOrder)
  ADJUST_PRICE        - Adjust price by percentage (requires percentage, positive=increase, negative=discount)
  SET_STOCK           - Set stock quantity (requires stock)

Request Body Examples:

Move to category:
{
  "productIds": [10, 11],
  "action": "MOVE_CATEGORY",
  "categoryId": 3
}

Adjust price (10% increase):
{
  "productIds": [10, 11, 12],
  "action": "ADJUST_PRICE",
  "percentage": 10.0
}

Set stock:
{
  "productIds": [10, 11],
  "action": "SET_STOCK",
  "stock": 50
}

Response:
{
  "success": true,
  "affectedCount": 4,
  "action": "ACTIVATE",
  "message": "Bulk action ACTIVATE applied to 4 products"
}

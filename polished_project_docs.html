ABSTRACT

The increasing reliance on cloud storage services has raised significant concerns regarding data confidentiality, integrity, and unauthorized access. To address these challenges, this work presents a secure cloud-based file encryption system designed to protect sensitive user data before it is uploaded to remote servers. The system employs strong cryptographic algorithms, such as AES and RSA, to ensure end-to-end security by encrypting files locally on the user’s device and allowing only authenticated users to decrypt them.

By integrating user authentication, key-management mechanisms, and seamless cloud interaction, the proposed solution enhances trust and privacy in cloud environments. Experimental evaluation demonstrates that the system achieves efficient performance with minimal overhead while providing robust protection against common security threats, including data breaches, man-in-the-middle attacks, and unauthorized retrieval. This approach enables users to safely store and share files in the cloud without compromising security, making it suitable for personal, enterprise, and distributed computing scenarios.

## One-Line Pitch

Anusha Bazaar is a full-stack hyperlocal grocery and essentials commerce platform connecting customers, local stores, administrators, and delivery partners through one secure digital ecosystem.

## Problem

Local grocery stores and small retailers often lack integrated technology for online ordering, catalog management, payments, delivery assignment, customer engagement, and operational analytics. Customers expect fast delivery and transparent tracking, while delivery partners need reliable onboarding, verification, order execution, and payout workflows.

## Solution

Anusha Bazaar provides a customer app, admin panel, delivery partner app, website, and Spring Boot backend. The platform supports product discovery, cart, checkout, Razorpay payments, Firebase phone authentication, JWT-secured APIs, coupons, referrals, wallet, banners, notifications, delivery partner KYC, admin approval, live delivery flows, payouts, WhatsApp campaigns, and cloud deployment.

## Innovation

- Complete customer-admin-delivery-backend commerce stack.
- Firebase OTP authentication with backend JWT security.
- Delivery partner KYC, approval, vehicle, bank, and payout workflow.
- Delivery OTP, location updates, and proof-of-delivery support.
- Super admin governance with modular permissions, access codes, and audit logs.
- Growth tools including referrals, scratch cards, coupons, banners, push notifications, and WhatsApp campaigns.

## Technology Stack

- **Mobile:** React Native, Expo, Firebase, Razorpay.
- **Web/Admin:** React, TypeScript, Vite, Material UI, Redux Toolkit.
- **Backend:** Java 17, Spring Boot 3.4.2, Spring Security, JWT, Spring Data JPA.
- **Cloud:** AWS RDS MySQL, AWS S3, Docker, GitHub Actions, Amazon ECR, EC2.
- **Engagement:** Firebase Cloud Messaging, WhatsApp campaign support, email service.

## Impact

Anusha Bazaar helps digitise local retail, improves access to groceries and essentials, creates delivery partner earning opportunities, supports transparent payments and order records, and provides local merchants with modern commerce tools.
